# 新星創客冬令營純前端宣傳單頁 UI/UX 設計與開發規格書 (Spec)

## 專案概述 (Overview)
- **頁面名稱**：新星創客冬令營一頁式宣傳頁 (Winter Maker Camp Landing Page)
- **功能簡述**：提供家長快速了解冬令營成果、接送時程與方案費用，並一鍵引導至 LINE ID (`ddchen0116`) 諮詢報名的一頁式純前端宣傳網頁。
- **技術架構**：純靜態前端 (Vanilla HTML5 + Modern CSS3 + Native ES6 JavaScript)，無後端、無龐大第三方庫依賴，極速秒開與 100% 響應式。
- **唯一轉換終點**：LINE 諮詢與報名 (`ddchen0116`)。
